プライバシーポリシー（kanzaki-pdca）

最終更新日：2026年11月18日

取得する情報

本ツールは、利用者が許可した場合に限り、YouTube Data API および YouTube Analytics API を通じて、利用者自身のチャンネルの動画情報とアナリティクス指標を読み取り専用（youtube.readonly / yt-analytics.readonly）で取得します。

利用目的

取得した情報は、利用者自身が動画企画の振り返りを行う目的にのみ使用します。

保存と共有

情報は利用者自身のコンピュータ内にのみ保存され、第三者に提供・販売することはありません。本ツールはYouTubeのデータを変更・投稿する権限を持ちません。

アクセスの取り消し

利用者はいつでも Googleアカウントの権限設定 から本ツールのアクセスを取り消せます。

本ツールによるGoogle APIから取得した情報の使用は、Google API Services User Data Policy（Limited Use要件を含む）に準拠します。
